# Official Docs Sources

Retrieved: 2026-06-29 JST

## Python Packaging

- PyPA specification: Declaring project metadata.
  https://packaging.python.org/en/latest/specifications/declaring-project-metadata/
- PyPA specification: `pyproject.toml`.
  https://packaging.python.org/en/latest/specifications/pyproject-toml/

Decision:

- `pyproject.toml` is the authoritative default Python project metadata file.
- `[project].requires-python` is treated as the default runtime compatibility
  declaration.
- `[project].dependencies` and `[project].optional-dependencies` are treated as
  dependency declarations.
- For this repository, `dependencies = []` means the default stdlib loop has no
  external Python dependency to lock. Optional MiniGrid/BabyAI and PyTorch lanes
  remain outside the default dependency set unless the project metadata changes.

## GitHub

- GitHub Docs: Creating a pull request template for your repository.
  https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/creating-a-pull-request-template-for-your-repository

Decision:

- `.github/pull_request_template.md` is used as the default PR review checklist
  for this repository.
- The template explicitly asks for verification commands, optional-dependency
  status, research result notes, and secret/fleet evidence boundaries.
